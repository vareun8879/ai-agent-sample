# 기존 규칙 이관 검토

| 기존 처리 | v2 처리 | 주의 |
|---|---|---|
| 한국어 조사·공백·영문 낱말 대조 | 기존 textutil을 검색 후보 보강에 사용 | 단독 차단 기준으로 사용하지 않음 |
| 복합 질문 분해 | 기존 표지 기반 두 항목 분해 재사용 | 복잡한 세 항목 이상은 별도 평가 필요 |
| 숫자·날짜 | 항목이 인용한 구절의 값과 대조 | 날짜 형식·단위 생략 오탐은 log로 먼저 확인 |
| 금액 | 원 단위로 정규화해 범위 끝값 대조 | 단위 없는 금액을 임의 환산하지 않음 |
| 인용 실재 여부 | 해당 항목에 제공된 근거 ID와 원문 대조 | 문서 전체에 같은 값이 있어도 자동 인정하지 않음 |
| 담당자 이름·연도·순번 | 원문 claim과 생성 답 구조로 전달 | 기존 휴리스틱과 동등한 의미 검증이라고 주장하지 않음 |
| 여러 경로의 재생성·한 줄 재답 | pipeline 전체 2회 예산 | 각 모듈은 재시도를 소유하지 않음 |
| 거절 재질문 | 근거 부족 상태를 별도로 반환 | 검색 실패와 문서에 없음은 구분 |
| 페이지 전체 확장·특정 행 보너스 | 항목별 리랭킹 및 근거 예산 | 정답 페이지 누락 여부를 기준선과 비교 |
| 마지막 답변 라벨 선택 | JSON 전체 파싱, 항목 ID 중복/누락 거부 | 정보 손실을 성공으로 처리하지 않음 |
| 괄호 숫자 제거·응답 문자열 보정 | 원문 보존, 출력 값 검사 | 표 구조 자체의 복원은 다음 인덱싱 회차 |

새 평가의 numeric rubric은 일부 수치 문항에 먼저 적용했다. 설명형·이름형 문항은 아직 legacy_only이며,
자동 채점이 보장하지 않는 의미적 오류는 수동 검토가 필요하다. 새 기준의 완성된 120문항 점수로 보고하지 않는다.
